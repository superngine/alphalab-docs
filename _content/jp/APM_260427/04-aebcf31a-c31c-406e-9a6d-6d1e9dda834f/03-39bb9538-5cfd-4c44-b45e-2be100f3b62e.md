# 러프,스케치 기반 인물 생성 사례 몇가지

 **러프스케치 기반 인물 생성** 

인물생성  


![7d271fd4\-476e\-4743\-9f84\-a5423d3b0656](manual-asset://6947594c-b92b-481e-984a-7cc6ac75e9ac)

Sketch 선택

- 러프스케치(메인이미지)와 참조이미지(캐릭터시트)를 첨부합니다.  
- 명령어(프롬프트)를 입력합니다.  
- 스케치의 강도를 조절합니다.  
- 생성버튼을 누릅니다.

  Tip러프스케치 기반의 이미지들은 
  ![7d271fd4\-476e\-4743\-9f84\-a5423d3b0656](manual-asset://6947594c-b92b-481e-984a-7cc6ac75e9ac)

  Sketch 모드를 꼭 선택해주세요

   강도를 낮출수록 러프스케치의 선 영향을 강하게 받고 (숫자 값 1에 근접)

    강도를 높일수록 러프스케치의 선 영향을 약하게 받아 생성됩니다. (숫자 값 30에 근접)

    사람마다 다르게 느낄 수 있어서 강도 조절을 자유롭게 설정해서 생성해보세요.

  **ㄴ예시키워드: 레퍼런스이미지(비율은 잘 맞추어져 있지만 선이 너무 정돈되지 않은 이미지)+디테일(명령어)+캐릭터시트**

캐릭터 시트 생성

- 캐릭터시트를 만들 캐릭터의 전신이미지를 첨부해주세요.  
- 캐릭터시트의 베이스시트 이미지를 러프스케치로 첨부해주세요.  
- 베이스시트 이미지의 위치는 ‘선택이미지(메인이미지)’,전신이미지는 ‘참조이미지’위치하게 해주세요.  
- 
  ![7d271fd4\-476e\-4743\-9f84\-a5423d3b0656](manual-asset://6947594c-b92b-481e-984a-7cc6ac75e9ac)

  Sketch 모드 선택해주세요. 강도(DOF)는 13-15로 조절해주세요.  
- 명령어(프롬프트):러프스케치 참고해서 삼면도 만들어줘,참조이미지의 캐릭터로 전면,측면,후면,다양한 얼굴표정 만들어줘,하얀배경으로 생성  
- 생성버튼을 누릅니다.

  Tip  캐릭터시트로 만들 전신이미지는 반측면 전신이미지가 가장 좋습니다. 
  ```
  ( 반측면 이미지가 없다면 정면 전신이미지를 사용해주세요.)
  ```

   강도(DOF)의 수치는 생성된 이미지를 확인하시면서 조절해서 생성해주세요.

  **ㄴ예시키워드: 전신이미지+베이스시트이미지+명령어(적혀있는그대로)**
