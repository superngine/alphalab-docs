# Precautions when using AlphaLab AI  


- **Resolution of generated images**  
Unless otherwise specified, images will be generated with the same resolution as the main reference image, such as a storyboard.  

- **Resolution of reference images**  
The recommended resolution for reference images is 1024x1024 (minimum 512x512 \~ maximum 2560x2560).   
Images that are too small, too large, or blurry may be unsuitable as reference images.  
  

- **Slowdown or failure of image generation**   
If other users are generating images, image generation may be delayed.  
If image generation requests are repeatedly made by clicking the image generation button or refreshing, the image generation speed may decrease.   
 If the generation speed continuously decreases or fails, please contact us.
