# Change Character Style

**Edit+Fx**This is a tutorial on generating using the feature.

- Use the 'Edit' feature in Edit+FX. 
- The 'Edit' feature is a feature that focuses on maintaining the art style. It is used when you want to naturally change only specific elements while leaving the overall art style of the image and the shape of the character intact. 
- It preserves the original line feel, coloring style, and character's impression as a top priority, and reconstructs only specific objects according to the entered command (prompt).
