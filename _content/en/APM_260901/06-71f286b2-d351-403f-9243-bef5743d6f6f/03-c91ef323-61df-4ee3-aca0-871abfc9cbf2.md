# Create Character Sheet

**Pose** This is a tutorial on generating using the feature.

- Using the Pose feature, you can easily create a character sheet with a base sheet and a single character image.
- The most important thing is the base sheet, which contains information on the body type and proportions of the character you want. 
- You can determine how much the body type and proportions of the base sheet are reflected by selecting the freedom. 
  - Freedom determines the range of variation. 
  - The lower the strength, the stronger the influence of the base image's lines (L),
  - The higher the strength, the weaker the influence of the base image's lines during generation. (H)
- Since everyone may perceive it differently, try generating by freely adjusting the strength. 
  - The default value for freedom and density is 'M'.
