# Background Generation and Modification

**Edit+Fx**This is a tutorial on generating and modifying backgrounds using the feature.

- This is a tutorial that combines the style preservation of 'Edit' with the post-correction features of 'FX'.
- You can generate a natural background using a photo or 3D material as the base image. 
- You can create your desired atmosphere with the generated background images. 
- 'Edit' is responsible for preserving the art style, and 'FX' is responsible for creating the atmosphere! With just one Edit+FX button, you can safely add sophisticated post-correction effects without worrying about the art style changing!
