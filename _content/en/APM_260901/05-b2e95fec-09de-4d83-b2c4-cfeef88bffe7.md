# Tutorial

**Basic instructions before generating images with the AlphaLab solution**

- 'Number of images' is the number of images to output at once. (You can output up to 4 images.)
- All tasks will be output only after pressing the 'Generate' button at the end. (The shortcut is Windows: Ctrl+Enter / Mac: Cmd+Enter.)  
- When working with a white background, it is recommended to emphasize "white background", "white background", or "whitebackground" in the command (prompt).  
- The generated image is created at the size of the base image added to the prompt window, so it is recommended to prepare the reference image at an appropriate resolution of 3000×3000px or less.
