# Introduction to Alphalab AI

![image\-8571189c\-93ce\-46bf\-a519\-d131bb33acf1](manual-asset://3344bd9f-8ff4-472a-b62d-13233b87fc6a)

**Alphalab Plus** sincerely welcomes you!

**Alphalab Plus** supports a workflow that generates images using an AI conversational thread method and iteratively improves them.   


---

**Key Features**

- **Thread-based Management:** Saves and manages a single workflow in thread units. 
- **Iterative Generation** · **Quality Improvement:** Iteratively generates images within the same thread to improve quality. 
- **Image Library** **:** Browse and manage generated images directly within the browser, and easily reuse them with the library feature.
