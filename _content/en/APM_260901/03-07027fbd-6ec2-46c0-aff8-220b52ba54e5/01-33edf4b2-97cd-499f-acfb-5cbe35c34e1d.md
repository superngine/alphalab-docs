# Main Screen with an interactive UI specialized for image creation

- Alphalab adopts a familiar and intuitive interactive UI like ChatGPT, designed so that even first-time users can use it easily. 
- Because it uses a dedicated art style model with excellent consistency, you can create the image you want just by clearly communicating what you want to make, without any complex operations. 
- It allows you to easily reuse character sheets, outfit reference images, or generated images. 

Unfold your own unique artistic world easily and freely with Alphalab.
