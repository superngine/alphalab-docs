# Change style while maintaining composition

**Smart transformation that maintains the original composition and applies the style of the reference image**

- This feature transforms the image by bringing in the details of the reference image while preserving the overall composition and shape of the original image. 
- It is most efficient when you want to add only the art style or design elements of the reference image while maintaining the specific pose or arrangement of the original that is difficult to describe with text.
