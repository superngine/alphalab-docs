# Generate with Reference Image and Prompt

## **Add a friendly 'guide' to your imagination for a more detailed world of creation** 

- This is an advanced generation feature that simultaneously utilizes text commands (prompts) and visual reference images to realize the provided image based on the user's request. 
- While working, there are times when you feel a complexity that is hard to explain with words alone. In these cases, try attaching a reference image to use as a guideline! 
- It drastically reduces the trial and error that can occur when generating based solely on imagination,   
and it shows the best synergy especially when you want to maintain the characteristics of an existing character or reproduce the exact composition of a specific photo.
