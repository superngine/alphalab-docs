# Partial Regeneration \(Inpaint\)

## **Precise retouching that magically edits only the specified areas**

- This feature allows you to select a specific area you want to modify using a brush or mask and enter a command (prompt) to newly generate or naturally alter that image. 
- Without needing to regenerate from scratch, you can maintain the overall composition of the image while selecting only a specific area designated by the user to fix awkward parts,   
dramatically reducing work time and perfectly elevating the quality of the final result.

**&lt; Tips &gt;** 

- The Inpaint feature of the AlphaLab solution provides brush size adjustment and brush color change!
- If the area you want to fix is the 'pants' in the image, please select an area slightly wider than the actual pants. 
- If a part of the 'pants' is not included in the selection area, that part will be excluded from the retouching. 
- Selecting an area slightly wider than the part you want to change yields safer results.
