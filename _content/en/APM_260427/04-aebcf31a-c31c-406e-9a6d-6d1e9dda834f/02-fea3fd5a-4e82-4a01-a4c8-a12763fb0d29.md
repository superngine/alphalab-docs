# Character Generation

{{manual-highlight:#dcfce7}}**This section is currently scheduled for an update.**{{/manual-highlight}}

***“When generating an image with Text to Image, please select the image size first. It is located at the top left of the prompt window.”***

Text to Image

- Please select the size of the image to generate first. (Location: 'Image Size' at the top left of the prompt window)  
- Enter the command (prompt).  
- Click the Generate button.

  **└ Example keyword: Detail + Gender**

Text to Image  Ref

- Please select the size of the image to generate first. (Location: 'Image Size' at the top left of the prompt window)  
- Attach a reference image.  
- Enter the command (prompt).  
- Click the Generate button.

  **└ Example keyword: Reference image + Detail (Command)**

Image to Image

- Attach the image to be changed.  
- Enter the command (prompt).  
- Click the Generate button.

  **└ Example keyword: Change outfit color**

Image to Image  Ref

- Attach the image to be changed and a reference image.  
- Enter the command (prompt).  
- Click the Generate button.

  **└ Example keyword: Change outfit color based on the reference**
