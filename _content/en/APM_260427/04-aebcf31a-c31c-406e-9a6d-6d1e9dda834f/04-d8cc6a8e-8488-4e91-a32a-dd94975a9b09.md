  Object Replacement Case 

  Method 1
- Attached images: Main image, reference image  
- Command (prompt): Change the hands in the main image to lace gloves referring to the reference image.
- Attach the image to be changed and the reference image to refer to.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: Add 'do not change parts other than the gloves' to the prompt to minimize variations.

  **ㄴExample keywords: gloves, hat, necklace, shoes**

  Method 2  Using Inpaint
- Attached image: Main image  
- Command (prompt): Change the hands in the selected area to lace gloves referring to the reference image.
- Attach the image to be changed.  
- Click the attached image and turn on the Inpaint feature.  
- Mask the hand area.  
- Attach the lace glove image as a reference image.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: Add 'do not change parts other than the gloves' to the prompt to minimize variations.

  **ㄴExample keywords: gloves, hat, necklace, shoes**

  

  Object Addition Case 

  Method 1
- Attach the image to be changed and the reference image to refer to.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: The more detailed the description in the prompt, the closer the generated image will be to what you want. Alternatively, if you want the reference image to be output without changes, please add an emphasizing phrase like 'generate the reference image with as few changes as possible'.

  **ㄴExample keywords: gloves, hat, necklace, shoes, headphones, ring, socks**

  Method 2  Using Inpaint  Please check if it is okay to suggest this method as there is an issue where the misalignment between the masked and unmasked areas is clearly visible.
- Attach the image to be changed.  
- Click the attached image and turn on the Inpaint feature.

  (Select the attached image thumbnail in the prompt window  Select the Inpaint button in the window)
- Mask the area where the object will be added.  
- Attach the hat image as a reference image.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: If the area of the inserted reference image is larger than the masked area, a part of the reference image 

     may be cut off. Please make the masked area slightly wider than the area where the object will be added.

  Adding 'generate the reference image so its shape is accurately represented' to the command (prompt) will result in a safer generation.

  **ㄴExample keywords: gloves, hat, necklace, shoes, headphones, ring, socks**
