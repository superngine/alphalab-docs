  Replace Background

  Method 1
- Attach the image to be changed.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: Add 'do not change parts other than the background' to the prompt to minimize variations.

  **ㄴExample keywords: plaza with a fountain, indoor with a visible window**

  Method 2  Using Reference Image
- 1. Attached image: Main image, reference image  
- 2. Command (prompt): Change the background of the main image to the reference image.
- Attach the image to be changed and the reference image to refer to.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: Add 'do not change parts other than the background' to the prompt to minimize variations.

  **ㄴExample keywords: plaza with a fountain, indoor with a visible window**

  Item Replacement Case 

  Method 1
- Attached image: Main image, reference image  
- Command (prompt): Change the hands in the main image to lace gloves referring to the reference image.
- Attach the image to be changed and the reference image to refer to.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: Add 'do not change parts other than the gloves' to the prompt to minimize variations.

  **ㄴExample keywords: gloves, hat, necklace, shoes**

  Method 2  Using Inpaint
- Attached image: Main image  
- Command (prompt): Change the hands in the selected area to lace gloves referring to the reference image.
- Attach the image to be changed.  
- Click the attached image and turn on the Inpaint feature.  
- Mask the hand area.  
- Attach a lace glove image as a reference image.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: Add 'do not change parts other than the gloves' to the prompt to minimize variations.

  **ㄴExample keywords: gloves, hat, necklace, shoes**

  

  Item Addition Case 

  Method 1
- Attach the image to be changed and the reference image to refer to.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: The more detailed the description in the prompt, the closer the generated image will be to what you want. Alternatively, if you want the reference image to be output without changes, please add an emphasis phrase like 'generate the reference image with as few changes as possible'.

  **ㄴExample keywords: gloves, hat, necklace, shoes, headphones, ring, socks**

  Method 2  Using Inpaint  Please check if it is okay to suggest this method as there is an issue where the misalignment between the masked and unmasked areas is clearly visible.
- Attach the image to be changed.  
- Click the attached image and turn on the Inpaint feature.

  (Select the attached image thumbnail in the prompt window  Select the Inpaint button in the window)
- Mask the area where the item will be placed.  
- Attach a hat image as a reference image.  
- Enter the command (prompt).  
- Click the Generate button.

  Tip: If the reference image area to be inserted is larger than the masked area, a part of the reference image 

     may be cut off. Please make the masked area slightly wider than the area where the item will be added.

  Adding 'generate the reference image so its shape is accurately represented' to the command (prompt) will result in a safer generation.

  **ㄴExample keywords: gloves, hat, necklace, shoes, headphones, ring, socks**
