# A few examples of rough sketch\-based character generation

 **Rough sketch-based character generation** 

Character generation  


Select LineBase

- Attach the rough sketch (main image) and reference image (character sheet).  
- Enter the command (prompt).  
- Adjust the intensity of the sketch.  

Click the Generate button.

**&lt;Tip&gt;**

For rough sketch-based images, please make sure to select the 'LineBase' button!

 The lower the intensity, the stronger the influence of the rough sketch lines (closer to the numeric value 1).

  The higher the intensity, the weaker the influence of the rough sketch lines during generation (closer to the numeric value 30).

  Since everyone may perceive it differently, try generating by freely adjusting the intensity settings.

**ㄴExample keywords: Reference image (well-proportioned but with unrefined lines) + Details (command) + Character sheet**

Character sheet generation

- Please attach a full-body image of the character to create the character sheet.  
- Please attach the base sheet image of the character sheet as a rough sketch.  
- Please place the base sheet image in the 'Selected Image (Main Image)' position, and the full-body image in the 'Reference Image' position.  
- Please select LineBase mode. Adjust the intensity (DOF) to 10-13.  
- Command (Prompt): Create a three-view drawing referring to the rough sketch, create front, side, back, and various facial expressions with the character in the reference image, generate with a white background.  

Click the Generate button.

**&lt;Tip&gt;**  A half-profile full-body image is best for the full-body image to be made into a character sheet. (If you don't have a half-profile image, please use a front full-body image.)

 Please adjust the intensity (DOF) value while checking the generated image.

**ㄴExample keywords: Full-body image + Base sheet image + Command (exactly as written)**
