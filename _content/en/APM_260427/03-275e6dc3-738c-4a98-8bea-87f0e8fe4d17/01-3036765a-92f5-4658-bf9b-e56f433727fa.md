# Text to Image

**The moment your imagination becomes a complete picture** 

Even without complex drawing skills, you can freely control the desired mood, subject, lighting, and art style using only language,  making it optimized for instantly visualizing creative ideas. 

This is a feature that generates a new image using the trained engine's art style when the user enters a sufficient text description of the image they want to create into the prompt window.
