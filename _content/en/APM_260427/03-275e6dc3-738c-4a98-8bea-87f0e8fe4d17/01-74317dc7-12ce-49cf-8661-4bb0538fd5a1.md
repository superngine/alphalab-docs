# Text to Image

**The moment your imagination comes to life as a picture** 

Even without complex drawing skills, you can freely control the desired atmosphere, subject, lighting, and art style using only language, making it optimized for instantly visualizing creative ideas. It is a feature that generates a new image in the trained engine's art style when the user enters a sufficient text description of the image they want to generate into the prompt window.
