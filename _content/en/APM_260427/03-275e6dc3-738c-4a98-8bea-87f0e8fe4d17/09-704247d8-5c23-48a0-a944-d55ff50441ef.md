# Image Library

**Image Library, your own perfect asset repository loaded with a single click**  
The Image Library is an integrated repository that systematically manages repeatedly used character sheets and assets for projects in one place, significantly reducing the hassle of finding and uploading files every time to increase work continuity. Register frequently used data just once. You can instantly load it with a single click without having to search for the file again for each new task. Especially in professional work environments where a specific art style or character appearance must be strictly maintained, you can use the registered assets as a guide to consistently manage the quality of the overall output.

**Folder Classification**: Don't worry if you have a lot of data. You can create folders by project or topic to neatly categorize and store related images.  
**Smart Search Feature**: Try searching by folder name or file name in the search bar at the top of the Image Library. You can find the images you need in just a few seconds, ensuring your workflow is not interrupted.  
**Pinning** : Keep your most frequently used files always at the top with the pinning feature to create a more convenient work environment.  
**&lt;Tip&gt;**  
To maximize the utilization of the Image Library, save file names as project names or easy-to-find keywords! You can pull out your own work tools much faster through the search feature.
