# Image Library

**Image Library, your own perfect asset warehouse loaded with a single click**

  
The Image Library is an integrated repository that systematically manages character sheets and assets repeatedly used in projects in one place, and the hassle of finding and uploading files every time is 

drastically reduced to enhance work continuity. Register frequently used data just once!

You can instantly load files with a single click without having to search for them again for each new task, and especially in professional work environments where a specific art style or character appearance must be strictly maintained, registered assets can be 

used as a guide to consistently manage the quality of the entire output.

**Folder Classification**: Don't worry even if the amount of data increases. You can create folders by project or topic to neatly separate and store related images.  
**Smart Search Function**: Try searching by folder name or file name in the search bar at the top of the Image Library. You can find the images you need in just a few seconds, so your workflow is not interrupted.  
**Pin** : The most frequently used files are always kept at the top with the pin function to create a more convenient work environment.  
**&lt;Tip&gt;**  
To maximize the utilization of the Image Library, save file names as project names or easy-to-find keywords! You can pull out your own work tools much faster through the search function.
