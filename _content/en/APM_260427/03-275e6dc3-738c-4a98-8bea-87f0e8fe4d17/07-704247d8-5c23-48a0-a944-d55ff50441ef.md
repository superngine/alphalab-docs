# Image Library

**Image Library, your own perfect asset repository that loads with a single click**  
The Image Library is an integrated repository that systematically manages repeatedly used character sheets and assets for projects in one place, dramatically reducing the hassle of finding and uploading files every time and increasing work continuity.

Register your frequently used data just once. 

You can instantly load files with a single click without having to search for them again for every new task. Especially in professional work environments where a specific art style or character appearance must be strictly maintained, you can use registered assets as guides to consistently manage the quality of the overall output.

**Categorization by folder**: Don't worry even if you have a lot of data. You can create folders by project or topic to neatly separate and store related images.  
**Smart search feature**: Try searching by folder name or file name in the search bar at the top of the Image Library. You can find the images you need in just a few seconds, so your workflow won't be interrupted.  
**Pinning** : The most frequently used files are always kept at the top with the pinning feature, creating a more comfortable work environment.

  
**&lt;Tip&gt;**  
To maximize the utilization of the Image Library, save file names as project names or easy-to-find keywords!  
 Through the search feature, you can pull out and use your own work tools much faster.
