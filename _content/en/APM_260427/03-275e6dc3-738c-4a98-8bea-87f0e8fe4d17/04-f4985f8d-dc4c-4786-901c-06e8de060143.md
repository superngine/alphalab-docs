# image to image Ref

**Smart transformation that maintains the original composition and applies the style of the reference image**

A feature that transforms the image anew by bringing in the details of the reference image while preserving the overall composition and shape of the original image. 

It is most efficient when you want to add only the art style or design elements of the reference image while maintaining the specific pose or layout of the original that is difficult to describe in text.
