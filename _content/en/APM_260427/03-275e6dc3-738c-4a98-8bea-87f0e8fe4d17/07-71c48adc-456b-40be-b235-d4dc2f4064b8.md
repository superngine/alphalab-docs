# Inpaint Liquify

**Magical retouching that adds sophisticated sculptural beauty** 

Try using Liquify in the Inpaint tool for the parts of the image you want to manually correct!

It is a partial liquify editing feature that allows you to freely correct shapes and proportions by flexibly pushing and pulling pixels within the area selected by Inpaint.

You can achieve clean results with a light touch and just a simple prompt describing the object to be corrected, allowing you to finely adjust awkward body proportions or the placement of facial features.
