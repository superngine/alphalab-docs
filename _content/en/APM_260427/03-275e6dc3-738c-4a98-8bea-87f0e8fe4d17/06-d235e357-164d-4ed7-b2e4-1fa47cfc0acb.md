# Inpaint

**Precise retouching that magically modifies only specific parts**

This feature allows you to select a specific area you want to edit using a brush or mask, and by entering a command (prompt), it generates a new image for that area or changes it naturally. 

Without the need to regenerate from scratch, it maintains the overall composition of the image while allowing you to select and fix only the awkward parts in a user-specified area, drastically reducing work time and 

perfectly enhancing the quality of the final result.
