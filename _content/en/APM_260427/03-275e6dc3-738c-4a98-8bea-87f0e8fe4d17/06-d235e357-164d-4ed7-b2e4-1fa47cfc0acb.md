# Inpaint

**Precise retouching that magically modifies only specific parts**

This feature allows you to select a specific area you want to modify using a brush or mask and write a command (prompt) to newly generate or naturally change that image. 

Without the need to regenerate from scratch, it maintains the overall composition of the image while allowing you to select only a specific user-designated area to fix awkward parts, drastically reducing work time and 

perfectly elevating the completeness of the final result.
