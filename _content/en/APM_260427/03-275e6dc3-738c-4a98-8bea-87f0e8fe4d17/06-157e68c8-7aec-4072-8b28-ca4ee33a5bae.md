**Inpaint**  
**Sophisticated retouching that magically modifies only specific parts**  
If you select a specific part you want to modify with a brush or mask and write a command (prompt),  
it is a feature that allows you to newly generate or naturally change the corresponding image.  
Without needing to regenerate from scratch, while maintaining the overall composition of the image, selecting only the specific area designated by the user  
allows you to pick and fix only the awkward parts, dramatically reducing work time and perfectly elevating the completeness of the result.  
**&lt;Tip&gt;**  
The Inpaint feature of the AlphaLab solution provides brush size adjustment and brush color change.  
If the area you want to fix is the 'pants' in the image, please select an area slightly wider than the pants in the image. If a part of the 'pants' is not designated as the selection area, it will be excluded from the retouching.  
Selecting an area slightly wider than the part you want to change brings safer results.

**Inpaint Liquify**  
**Magical retouching that adds sophisticated structural refinement**  
Try using Liquify in the Inpaint tool for the parts you want to manually correct in the image.  
It is a partial liquify editing feature that allows you to freely correct shapes or proportions by flexibly pushing and pulling the pixels of the image within the area selected with Inpaint.  
You can finely adjust awkward body proportions or the position of facial features, and obtain a clean result with a light touch just by using a prompt like 'clean up the image'.  
**&lt;Tip&gt;**  
**The magic of the brush:** Finely adjust the size and pressure of the brush.  
          Pushing large areas broadly to set the overall composition, and refining detailed parts with small and light pressure will yield a much more natural result.  
**Utilize the Restore feature:** Do not panic if you overdo it while adjusting the shape.  
          You can use the restore brush to revert only that part to its original shape and find the optimal point.
