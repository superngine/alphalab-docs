# Inpaint

**Inpaint**  
**마법처럼 부분만 수정하는 정교한 리터칭**  
수정하고 싶은 영역을 브러시나 마스크로 특정 부분으로 선택하고 명령어(프롬프트)를 작성하면  
해당 이미지를 새롭게 생성하거나 자연스럽게 바꿀 수 있는 기능입니다.  
처음부터 다시 생성할 필요 없이 이미지의 전체적인 구도는 유지하면서, 사용자가 지정한 특정 영역만 선택하여  
어색한 부분만 골라 고칠 수 있어 작업 시간을 획기적으로 단축하고 결과물의 완성도를 완벽하게 끌어올려 줍니다.  
**Tip**  
알파랩 솔루션의 인페인트 기능은 브러시의 크기 조절, 브러시 색상 변경을 제공합니다  
고치고 싶은 영역이 이미지 중 ‘바지’라면 이미지에서 바지의 영역보다 조금 더 넓게 영역을 잡아주세요  
‘바지’의 일부분이 선택영역으로 지정되지 않는다면 그 부분은 빼고 리터칭이 됩니다.  
변경을 원하는 부분보다 조금 더 넓게 영역을 잡는게 더 안전한 결과를 가져옵니다.



**Inpaint Liquify**  
**정교한 조형미를 더하는 마법의 리터칭**  
이미지에서 손수 교정하고 싶은 부분을 인페인트 툴에 있는 리퀴파이를 이용해보세요  
인페인트로 선택한 영역 내에서 이미지의 픽셀을 유연하게 밀고 당겨, 형태나 비율을 자유롭게 교정할 수 있는 부분 유동화 편집 기능입니다.  
어색한 인체 비율이나 이목구비의 위치를 세밀하게 조정하고 ‘이미지를 정리해줘’정도의 프롬프트만으로 가벼운 터치로 깔끔한 결과물을 얻으실 수 있습니다.  
**Tip**  
**브러시의 마법:** 브러시의 크기와 압력을 세밀하게 조절해 보세요.  
          넓은 영역은 크게 밀어 전체적인 구도를 잡고, 세밀한 부분은 작고 약한 압력으로 다듬으면 훨씬 자연스러운 결과물이 나옵니다.  
**복구(Restore) 기능을 활용하세요:** 형태를 만지다 과해졌다면 당황하지 마세요.  
    복구 브러시를 사용해 해당 부분만 원본의 형태로 되돌리며 최적의 지점을 찾아낼 수 있습니다.

**테스트 중인데 리퀴파이도 인페인트처럼 브러쉬영역이 마스킹으로 잡힙니다.**  
 **리퀴파이로 수정 후,브러쉬 영역을 삭제하고 생성하면 생성이 되지않고 다시 영역을 잡으라고 안내가 나옵니다.**  
**방식이 아직 정리가 안끝난상태같아 관련해서 상세한 설명이 힘듭니다.**
