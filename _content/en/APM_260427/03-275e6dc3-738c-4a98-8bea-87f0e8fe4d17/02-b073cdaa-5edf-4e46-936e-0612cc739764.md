# Text to Image Ref

**Add a friendly 'guide' to your imagination for a more detailed world of creation** 

This is an advanced generation feature that simultaneously utilizes text commands (prompts) and visual reference images (references) to generate images based on the user's request. 

While working, there are times when you encounter complexities that are hard to explain with words alone. At these times, try attaching a reference image and using it as a guideline! 

It drastically reduces the trial and error that can occur when generating based solely on imagination, and it demonstrates the best synergy especially when you want to maintain the characteristics of an existing character or exactly reproduce the composition of a specific photo.
