# Text to Image Ref

**Adding a friendly 'guide' to your imagination for a more detailed world of creation** 

This is an advanced generation feature that simultaneously utilizes text commands (prompts) and visual reference images (references) to realize the provided image based on the user's request. While working, there are times when you experience complexity that is difficult to explain with language alone. In these cases, try attaching a reference image to use as a guideline! It drastically reduces the trial and error that can occur when generating based solely on imagination, and it demonstrates the best synergy especially when you want to maintain the characteristics of an existing character or exactly reproduce the composition of a specific photo.
