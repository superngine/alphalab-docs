# Inpaint and Liquify

## **Inpaint** 

**Sophisticated retouching that magically modifies only specific parts** 

This is a feature that allows you to newly generate or naturally change an image by selecting a specific area you want to modify with a brush or mask and writing a command (prompt). Without the need to regenerate from scratch, it maintains the overall composition of the image while allowing you to select only the specific area designated by the user to fix awkward parts, drastically reducing work time and perfectly elevating the completeness of the result.

## **Liquify**

**Magical retouching that adds sophisticated sculptural beauty** 

Try using Liquify in the Inpaint tool for the parts of the image you want to manually correct! It is a partial liquify editing feature that allows you to freely correct shapes or proportions by flexibly pushing and pulling the pixels of the image within the area selected with Inpaint. You can finely adjust awkward body proportions or the position of facial features, and get clean results with a light touch just by using a prompt like 'clean up the image'.
