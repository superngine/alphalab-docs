# 인페인트 및 자유변형

Inpaint: Sophisticated retouching that magically modifies only specific parts. It is a feature that allows you to select a specific area you want to modify with a brush or mask and write a command (prompt) to newly generate or naturally change that image. Without the need to regenerate from scratch, it maintains the overall composition of the image while allowing you to select only the specific area designated by the user to pick out and fix awkward parts, dramatically reducing work time and perfectly elevating the completeness of the result. Liquify: Magical retouching that adds sophisticated sculptural beauty. Try using Liquify in the Inpaint tool for the parts you want to manually correct in the image. It is a partial liquify editing feature that allows you to flexibly push and pull the pixels of the image within the area selected by Inpaint to freely correct the shape or proportions. You can finely adjust awkward body proportions or the position of facial features, and get clean results with a light touch just by using a prompt like 'clean up the image'.
