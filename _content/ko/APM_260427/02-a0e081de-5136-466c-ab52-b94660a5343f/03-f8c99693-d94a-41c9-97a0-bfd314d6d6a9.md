# 생성 이미지

**창작 이미지와 레시피를 묶는 똑똑한 데이터 보관**

생성 이미지, 나의 창의력이 기록되는 공간 알파랩 솔루션을 통해 생성된 모든 이미지와 생성 방식, 날짜, 해당 이미지의 프롬프트 등이 상세 정보를 한눈에 확인하는 디지털 갤러리입니다. 과거의 작업 레시피를 복기하고 관리함으로써 작업의 일관성을 유지하고 이미지 생성 효율을 극대화해 줍니다.
