# 이미지 라이브러리

**이미지 라이브러리, 클릭 한 번으로 불러오는 나만의 완벽한 에셋 창고** 

이미지 라이브러리는 프로젝트에 자주 쓰이는 이미지 자원을 한곳에 모아 체계적으로 관리하는 기능입니다.  

매번 파일을 찾고 업로드하는 번거로움을 덜어주고, 작업의 연속성을 높여줍니다. 

자주 사용하는 이미지에 명확한 파일 이름을 붙여 라이브러리에 등록해 보세요.  

검색 기능을 통해 훨씬 더 빠르게 나만의 작업 도구를 꺼내 쓸 수 있습니다.
