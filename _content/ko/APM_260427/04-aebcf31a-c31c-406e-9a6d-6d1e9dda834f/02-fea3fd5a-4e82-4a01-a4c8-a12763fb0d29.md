# 인물 생성

{{manual-highlight:#dcfce7}}**해당 섹션은 현재 업데이트 예정입니다.**{{/manual-highlight}}

***“Text to Image로 이미지를 생성하실때는 이미지 크기를 먼저 선택해주세요. 프롬프트창에서 좌측 상단에 있습니다.”***

Text to Image

- 생성할 이미지 크기를 먼저 선택해주세요. (위치: 프롬프트창 좌측상단 ‘이미지 크기’)  
- 명령어(프롬프트)를 입력합니다.  
- 생성버튼을 누릅니다.

  **ㄴ예시키워드: 디테일+성별**

Text to Image  Ref

- 생성할 이미지 크기를 먼저 선택해주세요. (위치: 프롬프트창 좌측상단 ‘이미지 크기’)  
- 참조이미지(레퍼런스이미지)를 첨부합니다.  
- 명렁어(프롬프트)를 입력합니다.  
- 생성버튼을 누릅니다.

  **ㄴ예시키워드: 레퍼런스이미지+디테일(명령어)**

Image to Image

- 변경할 이미지를 첨부합니다.  
- 명령어(프롬프트)를 입력합니다.  
- 생성버튼을 누릅니다.

  **ㄴ예시키워드: 의상 색상 변경하기**

Image to Image  Ref

- 변경할 이미지와 참조이미지(레퍼런스이미지)를 첨부합니다.  
- 명령어(프롬프트)를 입력합니다.  
- 생성버튼을 누릅니다.

  **ㄴ예시키워드: 의상 색상 레퍼런스 참고해서 변경하기**
