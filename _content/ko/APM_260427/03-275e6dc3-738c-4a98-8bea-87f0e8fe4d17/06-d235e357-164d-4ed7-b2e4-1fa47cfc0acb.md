# Inpaint

**마법처럼 부분만 수정하는 정교한 리터칭**

수정하고 싶은 영역을 브러시나 마스크로 특정 부분으로 선택하고 명령어(프롬프트)를 작성하면  해당 이미지를 새롭게 생성하거나 자연스럽게 바꿀 수 있는 기능입니다. 

처음부터 다시 생성할 필요 없이 이미지의 전체적인 구도는 유지하면서, 사용자가 지정한 특정 영역만 선택하여 어색한 부분만 골라 고칠 수 있어 작업 시간을 획기적으로 단축하고 

결과물의 완성도를 완벽하게 끌어올려 줍니다.
