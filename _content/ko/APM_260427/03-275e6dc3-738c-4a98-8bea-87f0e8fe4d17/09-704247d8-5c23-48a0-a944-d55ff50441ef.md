# Image Library

**이미지 라이브러리, 클릭 한 번으로 불러오는 나만의 완벽한 에셋 창고**  
이미지 라이브러리는 프로젝트에 반복적으로 사용되는 캐릭터 시트와 에셋 등을 한곳에 모아 체계적으로 관리하는 통합 저장소로, 매번 파일을 찾고 업로드해야 하는 번거로움을 획기적으로 줄여 작업의 연속성을 높여줍니다. 자주 사용하는 데이터를 한 번만 등록해 두세요. 새로운 작업마다 파일을 다시 찾을 필요 없이 클릭 한 번으로 즉시 불러올 수 있으며, 특히 특정 화풍이나 캐릭터의 외형을 엄격하게 유지해야 하는 전문적인 작업 환경에서 등록된 에셋을 가이드로 활용해 전체 결과물의 퀄리티를 일정하게 관리할 수 있습니다.

**폴더별 분류**: 자료가 많아져도 걱정 마세요 프로젝트나 주제별로 폴더를 생성해 관련 이미지들을 깔끔하게 구분하여 보관할 수 있습니다.  
**스마트 검색 기능**: 이미지 라이브러리 상단의 검색창에 폴더 이름이나 파일명으로 검색해보세요 필요한 이미지를 단 몇 초 만에 발견할 수 있어 작업 흐름이 끊기지 않습니다.  
**핀 고정** : 가장 많이 사용하는 파일들은 핀 고정 기능으로 언제나 최상단에 유지시켜 더욱 편한 작업환경을 만들어 드립니다.  
**&lt;Tip&gt;**  
이미지 라이브러리의 활욜을 극대화 하려면 파일명을 프로젝트명이나 찾아보기 쉬운 키워드로 저장하세요! 검색 기능을 통해 훨씬 더 빠르게 나만의 작업 도구를 꺼내 쓸 수 있습니다.
