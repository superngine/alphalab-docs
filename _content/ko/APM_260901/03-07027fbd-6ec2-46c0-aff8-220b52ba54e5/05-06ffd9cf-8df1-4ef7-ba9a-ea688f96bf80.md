# 대화형 작업 공간

# **대화로 이미지를 그리는 편리한 작업 공간**

- 이미지 생성 요청과 생성된 이미지가 대화형으로 표시되는 작업 공간입니다. 
- 사용자 요청과 이미지 생성 결과를 시간 순서대로 확인할 수 있으며, 이전에 생성한 이미지를 참고 이미지로 활용해 편리하게 원하는 이미지를 생성할 수 있습니다.
